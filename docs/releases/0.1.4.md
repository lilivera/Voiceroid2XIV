# Voiceroid2XIV 0.1.4.0

Dalamudのカスタムプラグインリポジトリからインストール・更新できる初回公開版です。

- VOICEROID2の手動読み上げ、チャット読み上げ、SimpleVoiceroid2Proxy互換のローカルHTTP API。
- チャット読み上げは初期状態で無効。PT・アライアンスを含む全チャンネルの選択も初期状態ではOFF。
- 既存Proxyと接続ライブラリを合わせ、VOICEROID2を起動したまま切り替える際の接続失敗に対応。
- 操作用ヘルパーの管理者権限での起動に対応。
- 一覧用アイコン、ヘルパー、依存DLL、ライセンス文書を同梱。

## 導入

Dalamud設定のカスタムプラグインリポジトリに、次のURLを登録して保存し、一覧から `Voiceroid2XIV` をインストールしてください。

```text
https://raw.githubusercontent.com/lilivera/Voiceroid2XIV/main/pluginmaster.json
```

Dalamud API 15、Windows、.NET Framework 4.8.1、インストール済みのVOICEROID2と音声ライブラリが必要です。既存のSimpleVoiceroid2Proxyを終了してから、`/v2xiv` で接続してください。

開発版から切り替える場合は、開発版を無効化し、Dev Plugin Locationsの登録を無効にしてからインストールしてください。プラグイン設定ファイルはそのまま引き継げます。
