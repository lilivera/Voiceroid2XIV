# 実機での確認手順

自動テストでは確認できないゲーム内表示と実際の音声出力を、以下の順に確認します。

1. 既存Proxyを終了し、VOICEROID2の編集画面を用意する。Dalamudにプラグインを登録し、読み込みエラーがないことを確認する。
2. `/v2xiv` で設定画面を開き、接続してテスト文章を読み上げる。ゲームの入力やフォーカスが奪われないことを確認する。
3. 利用可能な話者名と区切り記号を文頭に入れ、話者が切り替わることを確認する。
4. 割り込みを無効にして長い文章を送信し、続けて別の文章を送る。前の発声が完了してから次が始まることを確認する。
5. 次の文章を待機させて「キューを消去」を押す。発声中の文章は継続し、待機中の文章が始まらないことを確認する。
6. キューを一時停止し、複数の文章を送る。再開後に順番に読み上げることを確認する。「停止」で現在の発声も終了することを確認する。
7. 割り込みを有効にして長い文章の途中で別の文章を送る。先の発声が中断して次が始まることを確認する。
8. HTTPを有効にして再接続する。READMEのGET・POSTを試す。ACT連携を利用する場合は送信先を同じポートに設定して確認する。
9. Echoを選びチャット読み上げを有効にする。`/echo テスト` を送り、選択したチャットだけが読まれることを確認する。`/echo <pause>` でキュー状態が変わらないことを確認する。
10. プラグインをアンロードし、HTTP待受と `Voiceroid2XIV.Bridge` が終了し、VOICEROID2本体は残ることを確認する。
11. 再ロードして設定が復元されることを確認する。自動接続を有効にした場合は、再ロード時に接続されることを確認する。
12. VOICEROID2を手動終了した場合に未接続・エラーが表示され、再接続で復旧できることを確認する。
13. 「ヘルパーを管理者権限で起動」を有効にして接続する。Windowsの確認をキャンセルすると理由が表示され、再試行して許可した場合に接続できることを確認する。
14. 管理者権限で接続した状態から切断・アンロードし、ヘルパーが終了することを確認する。FFXIVの起動権限が変わっていないことを確認する。
15. 既存Proxyで読み上げを確認してProxyだけを終了し、VOICEROID2を起動したまま本プラグインで接続・読み上げできることを確認する。接続ライブラリを更新した場合は特に確認する。

エラーは設定画面のメッセージと `/xllog` を確認します。接続に75秒、通常のヘルパー応答に5秒の上限があります。
